# Game

A cute top-down farming and adventure game built with Godot 4.

## Run

Open this folder in Godot 4 (Import > select `project.godot`) and press F5.

## Controls

- Arrow keys: move
- Space / Enter: plant, harvest, or sleep (at the house door)

## Progress

- Character creator (name, skin, hair, outfit)
- Farm with a house, crop plots, day/night cycle
